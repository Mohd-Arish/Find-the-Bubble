<h3 align="left">This is a simple browser-based bubble click game implemented using HTML, CSS, and JavaScript. The game generates bubbles with random numbers, and the player needs to click the bubbles that match a target number to increase their score. The game runs on a 60-second timer.</h3> 
<h3 align="left" font-weight="bold">Features: </h3>
Generates 110 bubbles with random numbers between 0 and 9. Displays a target number for the player to find among the bubbles. Updates the score when the correct bubble is clicked. A countdown timer from 60 seconds. Displays "GAME OVER" when the timer reaches zero. 
<h3 align="left" font-weight="bold">How It Works: Generating Bubbles:  </h3>
The makebubble function generates 110 bubbles with random numbers between 0 and 9 and adds them to the HTML element with the id pbtm. 
<h3 align="left" font-weight="bold">Setting the Target Number: </h3> The getHit function generates a random number between 0 and 9 and displays it as the target number the player needs to find. Running the Timer: The runtimer function initializes a countdown timer from 60 seconds, updating the timer display every second. When the timer reaches zero, it stops and displays "GAME OVER" in place of the bubbles. 
<h3 align="left" font-weight="bold">Score Management:  </h3> The scrincrease function increments the player's score by 10 points each time they click the correct bubble. 
<h3 align="left" font-weight="bold">Game Interaction: </h3>  An event listener on the pbtm element checks if the clicked bubble's number matches the target number. If the player clicks the correct bubble, the score is increased, and new bubbles are generated with a new target number.
